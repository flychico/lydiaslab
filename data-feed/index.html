Leo Data Feed

Leo’s own predictions and graded results, as one clean file per sport, for sites, apps, newsletters and researchers.

Every row is one game Leo read and graded: Leo’s win chance for each team, Leo’s margin and total where it makes one, the calls Leo made, the final score, the result and units of each call, and the reason for every miss. Every number is the read of record, the last one saved before the game started. Nothing written after the start is in the file.

The file holds Leo’s output only. It carries no sportsbook line, price or market number, and no third party stats beyond the final score.

What is in every file

Common columns, in this order where they apply: sport, season, week (NFL), game_date, game_id, away_team, home_team, start_utc, read_saved_utc, leo_win_prob_away, leo_win_prob_home, leo_margin_home, leo_total, final_away, final_home, overtime, then each call as side, result and units, then leo_right_winner, miss_reason and model_version.

Team names are written out in full. Miss reasons use the same labels as Leo’s public record pages: injury input, market knew, overtime, blowout, variance, model error. The column files above give every column’s type, unit and meaning.

What Leo promises about the data

Frozen before the game

Every number is the last read saved before the start. Late changes never reach the file.

Every result included

Losses and misses stay in the file beside the wins, the same as on the public record.

No guarantees

The data shows what Leo said and how it turned out. It is not betting advice and it does not promise future results.
